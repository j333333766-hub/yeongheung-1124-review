파일 간 연결 구조 만들기

같은 폴더에 세 개의 HTML 파일을 만들어 서로 이동하는 흐름을 완성합니다.

연결 구조 한눈에 보기

━━ 다음 · START   ╌╌ 이전 · 처음으로

다음·START은 오른쪽으로, 이전은 왼쪽으로 돌아가고, A02의 다음은 아래를 크게 돌아 index로 순환합니다.

1

index.html 만들기

시작 페이지입니다. 화면 가운데 START 버튼 하나만 둡니다.
  • START 버튼 → A01.html 로 이동
복사용 프롬프트
index.html 파일을 만들어줘. - 화면 정중앙에 "START" 버튼 하나만 배치한다. - START 버튼을 누르면 같은 폴더의 A01.html 페이지로 이동한다. - 버튼은 크고 보기 좋게, 배경과 색을 깔끔하게 스타일링한다. - 전체를 하나의 완성된 HTML 파일로 작성한다.
2

A01.html 만들기

가운데 페이지입니다. 이전·다음 버튼 두 개를 둡니다.
  • 이전 버튼 → index.html 로 이동
  • 다음 버튼 → A02.html 로 이동
복사용 프롬프트
A01.html 파일을 만들어줘. - 화면에 "이전" 버튼과 "다음" 버튼 두 개를 나란히 배치한다. - "이전" 버튼을 누르면 같은 폴더의 index.html 페이지로 이동한다. - "다음" 버튼을 누르면 같은 폴더의 A02.html 페이지로 이동한다. - 현재 페이지가 A01임을 알 수 있는 제목을 화면 가운데 표시한다. - 전체를 하나의 완성된 HTML 파일로 작성한다.
3

A02.html 만들기

마지막 페이지입니다. 이전·다음 버튼 두 개를 둡니다.
  • 이전 버튼 → A01.html 로 이동
  • 다음 버튼 → index.html 로 이동(처음으로)
복사용 프롬프트
A02.html 파일을 만들어줘. - 화면에 "이전" 버튼과 "다음" 버튼 두 개를 나란히 배치한다. - "이전" 버튼을 누르면 같은 폴더의 A01.html 페이지로 이동한다. - "다음" 버튼을 누르면 같은 폴더의 index.html 페이지로 이동한다(처음으로 돌아감). - 현재 페이지가 A02임을 알 수 있는 제목을 화면 가운데 표시한다. - 전체를 하나의 완성된 HTML 파일로 작성한다.
